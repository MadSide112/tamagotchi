# Tamagotchi Bot — Telegram Widget (Bot API 10.4)

> **Онлайн-превью виджета:** https://madside112.github.io/tamagotchi/

Питомец-тамагочи живёт прямо в чате Telegram как интерактивный виджет
(Bot API 10.4, релиз 9 ноября 2026). Состояние питомца полностью
серверно-авторитарное: виджет только отображает его и отправляет запросы.

## Архитектура

```
widget/template.html  ──рендер из chat_data──▶  пузырь сообщения в чате
   │  TelegramWidget.request('feed'|'play'|'sleep'|'pet'|'sync')
   ▼
bot/polling.py  ──▶ bot/handlers.py  ──▶ game/engine.py (чистая логика)
                        │                    │ tick(): деградация по времени
                        │                    │ apply(): действия, кулдауны
                        ▼                    ▼
                  bot/api.py            storage/db.py (SQLite)
        sendWidget / editMessageWidgetData / answerWidgetQuery
```

- **Состояние** — `chat_data` виджета (≤1024 байт JSON, ключи одной буквой):
  `r` ревизия, `n` имя, `h` сытость, `m` настроение, `e` энергия, `sl` спит,
  `s` стадия (яйцо → малыш → подросток → взрослый), `b` рождение, `t` тик.
- **Деградация** считается лениво на сервере от `last_tick` (голод −6/ч,
  настроение −4/ч, энергия −4/ч; во сне энергия +10/ч, голод −9/ч). Кап
  оффлайна 48 часов.
- **Действие**: виджет → `request` → сервер валидирует →
  `editMessageWidgetData` (новое состояние) → `answerWidgetQuery` (текст + снапшот
  состояния для мгновенной перерисовки). Commit только после успешного edit.
- **Фоновая синхронизация**: виджет шлёт `sync` при появлении на экране и
  раз в 45 секунд — питомец «деградирует» на глазах, пока смотришь чат.
- **Уведомления**: голод < 20 → `sendMessage` не чаще раза в 12 часов.

## Запуск

```bash
cd tamagotchi
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt          # aiohttp
cp .env.example .env                     # вписать токен из @BotFather
python main.py
```

1. Создай бота в **@BotFather** (`/newbot`), получи токен.
2. Впиши `TAMAGOTCHI_BOT_TOKEN=<токен>` в `.env` (или экспортируй в окружение).
3. `python main.py` — long polling, публичный HTTPS не нужен.
4. Открой чат с ботом, отправь `/start` — бот закрепит сообщение-виджет с яйцом.
5. Нажми «🍎 Кормить» — яйцо треснет и питомец вылупится.

Важно: клиент Telegram должен быть свежим (виджеты появились в клиентах
13.2+, Bot API 10.4 от 9 ноября 2026). В проде виджеты пока работают
только в личном чате с ботом — группы/инлайн на тест-сервере.

> **⚠️ Известная проблема (с 13.11.2026):** Telegram закрыл отправку
> виджетов для обычных ботов на проде — `sendWidget` возвращает
> `INPUT_MEDIA_WIDGET_NOT_ALLOWED` для любого бота и любого чата.
> Подтверждено мейнтейнером Bot API (levlam) в
> [issue #947](https://github.com/tdlib/telegram-bot-api/issues/947):
> «currently, general bots aren't allowed to use widgets even in private
> chats». Тоггла в BotFather нет (`docs/tgw-format.md`: серверный конфиг,
> no flag for widgets). Код бота корректен и заработает, когда Telegram
> снова откроет доступ; до того можно тестировать виджеты через тест-сервер
> Telegram или ждать.

python3 -m unittest discover -s tests     # движок: тик, действия, стадии, JSON-бюджеты

Локальный превью виджета (стаб TelegramWidget, как в официальных доках):
```bash
python3 -m http.server 8765
# открыть http://127.0.0.1:8765/tools/preview.html
```

## Лимиты виджета (учтены и покрыты тестами)

- HTML ≤ 32768 байт, ≤ 4096 после zlib level 9 (у нас ~2.7 КБ).
- `chat_data`/`public_data` ≤ 1024 байт; запрос `request` ≤ 64 байт;
  ответ `answerWidgetQuery` ≤ 1024 байт, окно 15 секунд.
- Песочница QuickJS без сети: нет fetch/XHR/WebSocket, внешних
  скриптов/шрифтов/картинок; SMIL-анимации SVG запрещены — только CSS.
- 5 запросов в 5 секунд на пользователя; BUSY при незавершённом запросе.

## Дорожная карта

- Смерть/убегание питомца при нулевых статах.
- Корм разных типов, цены и «монетки» за игры.
- Сон по расписанию, будильник через `sendMessage`.
- Shared-виджет на группу (когда Telegram выведет его из тест-сервера):
  общий питомец на чат через `public_data` + `editSharedWidgetData`.
- Вебхук вместо long polling для прод-инфраструктуры.
